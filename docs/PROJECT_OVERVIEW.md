# Bluefixx Project Overview

## 1. Product Context & Vision
**Bluefixx** is a trusted services marketplace designed to bridge the trust and discovery gap between everyday customers and skilled manual/technical workers (artisans, handymen, plumbers, electricians, painters, carpenters). Beyond simple job discovery, Bluefixx fosters skill elevation and structured apprenticeships for emerging talents.

## 2. Intended User Groups
1. **Customers**:
   - Post jobs, browse verified service providers, request quotes, schedule appointments, track job execution, make secure payments, and rate services.
2. **Workers & Artisans**:
   - Create verified profiles, showcase completed work portfolios, receive and bid on job requests, manage active contracts, receive payments, and build reputation.
3. **Talents & Apprentices**:
   - Discover structured training and mentorship opportunities, apprentice alongside master craftsmen, build verified credentials.
4. **Platform Administrators**:
   - Verify artisan credentials, oversee dispute resolutions, monitor marketplace health, handle compliance and financial reporting.

## 3. Product Scope: Current vs. Anticipated

### Current Implementation Scope (Frontend Foundation)
- Establish Next.js App Router baseline with strict TypeScript.
- Synchronize design system tokens (colors, typography, spacing, shadows) from `bluefixx-website`.
- Implement accessible core component primitives (`Button`, `Input`, `TextArea`, `Card`, `Badge`, `EmptyState`, `ErrorDisplay`).
- Set up standardized API integration layers and mock-data boundaries.
- Build systematic documentation and screenshot-driven workflows for iterative Figma delivery.

### Anticipated Future Functionality
- **Authentication**: Customer & worker sign-up, sign-in, password reset, role-based onboarding.
- **Worker Verification**: Document upload, identity checks, badge verification.
- **Job Flow**: Job posting wizard, matching engine, proposal management, milestone tracking.
- **Financials**: Escrow payments, transaction history, payouts.
- **Communication**: In-app messaging, real-time job status notifications.
- **Administration**: Moderation queues, analytics dashboards.

*Note: Future features must only be implemented when corresponding Figma designs and specifications are provided.*
